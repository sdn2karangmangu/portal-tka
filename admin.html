Panduan Menghubungkan ke Google Sheets & Apps Script (5 Menit Jadi)

Langkah 1: Buat Google Spreadsheet Baru

Buka sheets.new dan beri nama spreadsheet misalnya "Database Tryout TKA Siswa".

Langkah 2: Buka Apps Script & Tempel Kode

Di Google Sheets, klik menu Ekstensi (Extensions) → Apps Script. Hapus isi Code.gs bawaan, lalu salin dan tempelkan seluruh isi file Code.gs dari proyek ini.

Langkah 3: Jalankan Inisialisasi Otomatis (Opsional / Praktis)

Di editor Apps Script, pilih fungsi setupSheets dari dropdown atas, lalu klik Run. Script akan otomatis membuat 4 sheet (Users, Tryout, Konfirmasi, Pengumuman) beserta header kolom dan data awal!

Langkah 4: Deploy Web App

Klik tombol biru Deploy → New deployment. Pilih tipe Web app. Atur:
• Execute as: Me (email guru)
• Who has access: Anyone (Siapa saja)
Klik Deploy → Salin Web App URL yang berakhiran /exec, lalu tempelkan ke kolom input di atas!

4 Sheet yang Digunakan:

1. Users
ID, Nama, NIS, Kelas, Username, Password, Role
2. Tryout
ID, Judul, Mapel, Tanggal, Jam Mulai, Jam Selesai, Link TKA, Petunjuk, Status
3. Konfirmasi
ID, ID Tryout, NIS, Nama Siswa, Status Konfirmasi, Waktu Permintaan, Waktu Persetujuan
4. Pengumuman
ID, Judul, Isi Pengumuman, Tanggal, Status
